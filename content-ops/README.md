# content-ops

EnerTech Lab の記事運用資産を管理するディレクトリです。  
この配下は「調査・企画・執筆・検証」の運用ファイルを置く場所で、**アプリコードは置きません**。

## 構成
- `prompts/`: 調査・執筆・改善プロンプト置き場
- `briefs/`: 記事ブリーフ（読者、論点、構成、公開条件）
- `source-packs/`: 一次情報・公的情報・論文などのソース束
- `calendars/`: 編集カレンダー、公開計画
- `checks/`: 公開前チェック（品質・安全・根拠確認）

## 運用方針
- 初期は量産せず、高品質記事を優先する。
- 記事は固定テンプレート（導入 / 結論 / 物理解説 / 実用 / 参考ソース / FAQ）で統一する。
- ランキング量産、雑なアフィリエイト、根拠のない断定は行わない。
